# 本机逐表确认页

启动：

```powershell
python -X utf8 client/review_server.py --project config/project.example.json --root demo --port 8765
```

页面只绑定 `127.0.0.1`。打开启动时打印的地址，选择本表预览，检查全部差异、来源指纹和目标位置；填写确认人及说明，勾选本表同意后提交。审批接口带本次服务会话令牌并检查同源。页面使用文本方式展示单元格内容。

成功后得到批准 ID。执行方在原项目及根范围内用 `apply --preview <id> --approval <id>` 提交。每份批准绑定精确 preview token；来源改变时无法继续用旧批准。页面不会自动 apply，也不会替调用者逐步推进配方。

`approve` 命令是供真实人工决定录入的入口。AI 只有在当前会话已经得到对应表格的明确确认后才可代录，不得自行写“已人工确认”。隔离测试使用临时虚构工作簿，不产生真实业务批准。

此确认页是单机工具，不是面向公网的用户系统。它不会注册服务、开机启动、消息通知、安装插件或修改 AI 全局连接。若要接企业审批，需要实现真实身份验证、回调、批准范围匹配与回执验证，并增加测试；不得直接迁移其他项目的审批令牌。
